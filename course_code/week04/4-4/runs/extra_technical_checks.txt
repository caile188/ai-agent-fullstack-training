⑥ jieba 怎么切代码标识符
================================================================================
原文：is_session_valid 的边界规则是什么？now <= expires_at
jieba 切出来：['is', '_', 'session', '_', 'valid', ' ', '的', '边界', '规则', '是', '什么', '？', 'now', ' ', '<', '=', ' ', 'expires', '_', 'at']
标识符被切成了 is / _ / session / _ / valid 五段；
`<=` 没有被吃掉，而是切成 '<' 和 '=' 两个符号。
所以补英文标识符正则是为了多给一个整词，不是为了救回被吃掉的符号。
