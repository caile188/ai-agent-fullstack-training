# 登录会话有效期规则

适用服务：login_demo 登录服务。

## 有效期长度

- 管理后台的登录会话有效期为 30 分钟。
- 计时方式：从签发时刻开始计算，30 分钟后到期。
- 空闲会话不自动续期，必须由用户请求触发刷新。

## 到期边界

- 项目约定：当前时刻恰好等于到期时刻时，会话必须判定为无效。
- 也就是说，`now == expires_at` 属于已过期。
- 实现上有效条件写作 `now < expires_at`，不要写成 `now <= expires_at`。

## 续期

- 用户发起请求后，服务在响应返回前刷新 `expires_at`。
- 新的到期时间 = 请求到达时刻 + 30 分钟。

## 不适用范围

- 本节规则只约束登录会话，不适用于支付会话、匿名浏览会话。
