# 支付会话规则

适用服务：pay_gateway 收单网关。本文与登录服务无关。

## 有效期长度

- 支付会话有效期为 5 分钟。
- 超时后订单进入 `PAY_TIMEOUT` 状态，需要用户重新下单。

## 到期边界

- 支付会话在 `now >= expires_at` 时置为超时。
- 与登录会话不同，支付会话到期后不刷新，只能重建。

## 与登录会话的区别

- 登录会话 30 分钟、可续期；支付会话 5 分钟、不可续期。
- 两者共用 `expires_at` 字段名，排查问题时先确认是哪个服务的会话。
